### 3.5 (e) Inference / Evaluation Scripts & Decoding Loops

1. **Three Custom Decoding Loops in [`QwenWithLVR`](file:///home/devraj/MTok/external_models/lvr/repo/src/model/qwen_lvr_model.py#L100-L1098)**:
   - [`QwenWithLVR.generate`](file:///home/devraj/MTok/external_models/lvr/repo/src/model/qwen_lvr_model.py#L100-L356) inspects `decoding_strategy`:
     - **`decoding_strategy == "logits"`** $\rightarrow$ [`_lvr_deocding`](file:///home/devraj/MTok/external_models/lvr/repo/src/model/qwen_lvr_model.py#L359-L581):
       - Tracks per-sequence boolean state `lvr_mode_switch` and `lvr_Steps_left` (initialized to `lvr_steps`, e.g. 16).
       - Enters LVR mode when the sampled token is `self.config.lvr_start_id` (`151665`) and exits when `next_tokens == self.config.lvr_end_id` (`151668`) or `lvr_Steps_left <= 0` ([L463-L473](file:///home/devraj/MTok/external_models/lvr/repo/src/model/qwen_lvr_model.py#L463-L473)).
       - While `lvr_mode_switch` is `True`, passes `last_position_hidden_state = outputs.last_hidden_state` into the next forward step, which overwrites `inputs_embeds[lvr_mode_switch, -1, :]` ([`src/train/monkey_patch_forward_lvr.py` L392-L403](file:///home/devraj/MTok/external_models/lvr/repo/src/train/monkey_patch_forward_lvr.py#L392-L403)), and forces `next_tokens = torch.where(lvr_mode_switch, self.config.lvr_id, next_tokens)` ([`src/model/qwen_lvr_model.py` L522-L526](file:///home/devraj/MTok/external_models/lvr/repo/src/model/qwen_lvr_model.py#L522-L526)) until `<|lvr_end|>` is sampled or `lvr_Steps_left` hits 0 (at which point `<|lvr_end|>` is forcefully emitted at [L530-L534](file:///home/devraj/MTok/external_models/lvr/repo/src/model/qwen_lvr_model.py#L530-L534)).
     - **`decoding_strategy == "latent_end"`** $\rightarrow$ [`_lvr_deocding_with_latentend`](file:///home/devraj/MTok/external_models/lvr/repo/src/model/qwen_lvr_model.py#L583-L852):
       - Exits LVR mode when the MSE/MAE/cosine distance between `last_position_hidden_state` and `self.lvr_latent_end_emb` falls below `self.config.latent_end_cri` ([L704-L746](file:///home/devraj/MTok/external_models/lvr/repo/src/model/qwen_lvr_model.py#L704-L746)).
     - **`decoding_strategy == "steps"`** $\rightarrow$ [`_lvr_deocding_by_steps`](file:///home/devraj/MTok/external_models/lvr/repo/src/model/qwen_lvr_model.py#L855-L1098):
       - Deterministically runs for a fixed quota of `lvr_steps` (e.g. 4, 8, or 16) continuous latent steps once `<|lvr_start|>` is emitted, ignoring `<|lvr_end|>` logits during latent steps and forcefully emitting `self.config.lvr_end_id` when the counter reaches 0 ([L972-L1044](file:///home/devraj/MTok/external_models/lvr/repo/src/model/qwen_lvr_model.py#L972-L1044)).

2. **Benchmark Evaluation Pipeline ([`evaluation/evaluation.py`](file:///home/devraj/MTok/external_models/lvr/repo/evaluation/evaluation.py#L1-L460))**:
   - [`load_model_and_processor`](file:///home/devraj/MTok/external_models/lvr/repo/evaluation/evaluation.py#L104-L122) calls `replace_qwen2_5_with_mixed_modality_forward_lvr(inference_mode=True, lvr_head=model_lvr_head)` and loads `QwenWithLVR.from_pretrained(..., torch_dtype=torch.bfloat16, attn_implementation="flash_attention_2")`.
